## Задание 1.3. Имена
### Текст задачи

Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду: Фамилия Имя Отчество. Предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду. Создать имена: Клеопатра, Пушкин Александр Сергеевич, Маяковский Владимир.
### Алгоритм решения

Создан класс Name с тремя строковыми полями. В конструкторе используются параметры по умолчанию (""), что позволяет создавать объекты только с именем или с именем и фамилией. Метод ToString() проверяет каждое поле на пустоту с помощью empty() и конкатенирует только заполненные части.

## Задание 2.3. Человек с родителем

## Задание 4.6. Создаем Человека
### Текст задачи

Измените сущность Человек. Человека можно создать с именем-строкой, с именем-строкой и отцом, с именем-объектом, с именем-объектом и отцом. Операции присвоения должны использоваться только в одном из конструкторов. Создать: Льва (170), Пушкина Сергея (168) с отцом Львом, Александра (167) с отцом Сергеем.
### Алгоритм решения

В классе Human реализованы перегруженные конструкторы. Чтобы выполнить требование о единственном присвоении, используется делегирующий конструктор: конструктор, принимающий строку, вызывает другой конструктор (Human(Name(name), height, father) {}), передавая туда созданный объект Name. Применение отца происходит в базовом конструкторе.

## Задание 5.2. Кот мяукает
### Текст задачи

Создайте сущность Кот. Имеет имя. Для создания нужно указать имя. Может быть приведен к строке "кот: Имя". Может помяукать: "Имя: мяу!". Может помяукать N раз: "Имя: мяу-мяу-...-мяу!". Создать кота "Барсик", помяукать 1 раз, затем 3 раза.
### Алгоритм решения

Создан класс Cat с полем имени. Реализована перегрузка методов: Meow() (без параметров) выводит одно "мяу", а Meow(int times) в цикле выводит "мяу", разделяя их дефисами. Для дружественного интерфейса добавлен запрос количества мяуканий через функцию безопасного ввода.
