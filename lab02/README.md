# Задание 2. Вставка элементов
## Задача 8
### Текст задачи

Дан дек D с четным количеством элементов. Вставить перед каждым элементом из первой половины исходного дека число –1. Использовать функцию-член insert в цикле с числовым параметром.

Итератор устанавливается на начало второй половины дека с помощью std::advance. В цикле выполняется сдвиг итератора на шаг назад (на элемент первой половины) и вызов insert для вставки -1. Результат вставки присваивается итератору.

# Задание 5. Алгоритмы поиска
## Задача 3
### Текст задачи

Дан список L. Удалить первый и последний нулевой элемент списка. Если нулевых элементов нет, то список не изменять, если нулевой элемент всего один, то удалить только его. Использовать два вызова алгоритма find и два вызова функции-члена erase.
### Алгоритм решения

Сначала алгоритм std::find ищет первый ноль с начала списка. Затем std::find с обратными итераторами (rbegin, rend) ищет последний ноль. Обратный итератор переводится в обычный с помощью .base(). Обрабатываются случаи, когда нулей нет или он один.

# Задание 6. Базовые модифицирующие алгоритмы
## Задача 3
### Текст задачи

Дано число N (> 0) и дек D, содержащий не менее 2N элементов. Заполнить первые N элементов дека последовательностью чисел 1, 2, ..., N, а последние N элементов дека — последовательностью N, N-1, ..., 2, 1. Использовать два вызова алгоритма generate с одинаковым параметром — функциональным объектом, а также обратные итераторы.
### Алгоритм решения

Создан функциональный объект (структура Counter), который инкрементирует внутреннее значение и возвращает его. Первый вызов std::generate заполняет начало дека. Второй вызов std::generate с обратными итераторами (rbegin) заполняет конец дека (визуально числа встают в обратном порядке).

# Задание 7. Сортировка и слияние
## Задача 13
### Текст задачи

Дан вектор V, количество элементов которого делится на 3. Известно, что каждая треть вектора уже упорядочена по возрастанию. Решить задачу, используя два вызова алгоритма inplace_merge с одним и тем же параметром — функциональным объектом.

Используется функциональный объект std::less<int>. Первый вызов std::inplace_merge сливает первую и вторую трети вектора. Второй вызов сливает получившуюся отсортированную часть с третьей третью.

# Задание 8. Численные алгоритмы
## Задача 2
### Текст задачи

Дан список L, элементами которого являются английские слова. Получить дек D со строковыми элементами, каждый из которых строится по паре соседних элементов исходного списка L следующим образом: последняя буква правого элемента пары приписывается справа к первой букве левого элемента пары. Использовать алгоритм adjacent_difference.
### Алгоритм решения

Используется std::adjacent_difference с std::back_inserter и лямбда-функцией. Лямбда берет первую букву предыдущего элемента (prev[0]) и последнюю букву текущего (curr.back()). Первый скопированный элемент удаляется из дека через erase.

# Задание 9. Множества
## Задача 2
### Текст задачи

Дан вектор V0, целое число N (> 0) и набор векторов V1, ..., VN. Найти количество векторов VI, в которых содержатся все элементы вектора V0 (с учетом повторений). Использовать алгоритм includes, применяя его к двум мультимножествам (multiset).
### Алгоритм решения

Вектор V0 и каждый из векторов VI конвертируются в std::multiset (это сохраняет дубликаты элементов). Затем в цикле для каждой пары мультимножеств вызывается std::includes, который проверяет, содержит ли текущий вектор все элементы из V0.

# Задание 10. Отображения
## Задача 3
### Текст задачи

Дан вектор V. Выполнить группировку элементов вектора V, используя в качестве ключа группировки последнюю (правую) цифру элемента. Представить результат в виде мультиотображения M (multimap). Вывести полученное отображение.
